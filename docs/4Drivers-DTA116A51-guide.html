4Drivers Daikin DTA116A51 VRV VRF UI Gateway

Manufacturer: Daikin (via 4Drivers)Hardware: DTA116A51 adapter (RS-485)Minimum OS: Control4 3.3.0

Overview

The 4Drivers Daikin DTA116A51 VRV VRF UI integrates Daikin VRV/VRF systems with Control4 through the Daikin DTA116A51 adapter (RS-485). One adapter controls up to 64 indoor units (4 DIII-Net groups of 16).

  • A single connection for all thermostats: each 4Drivers Daikin Thermostat binds to the gateway on its own and tells which unit it controls through its Unit ID
  • Web UI on the driver button (Navigator/Composer): control and readings of every unit, with "Find units" and "All Off"
  • Cool, Heat, Fan, Auto and Dry modes; Low/Medium/High fan; P0-P4 and Swing louver
  • Daikin error code (e.g. U4, A3), Forced Off and Cool/Heat master per unit
  • Celsius or Fahrenheit
  • Adjustable on/off methods for sites where the original Daikin controller is also used
  • Built-in 4Drivers licensing/trial
This driver has no thermostat card. To get a card for each indoor unit on the Control4 interfaces, add one 4Drivers Daikin Thermostat per unit. Without a thermostat, a unit can be controlled from the Web UI only.

Requirements

  • DTA116A51 adapter (or newer, same protocol) installed on the DIII-Net bus
  • Board ID starting with EB (e.g. EB11042(A)). DCPP boards are not compatible
  • Controller serial port with a powered RS-232/RS-485 converter, or an IP/RS-485 converter with the 4Drivers RS-232 RS-485 - IP Gateway driver
  • Control4 OS 3.3.0 or later (required by the Web UI)
Board ID starting with EB

Step-by-Step Setup

1 — DTA116A51 board

  1. Set DS1 to 19200 8 even 1 (19200 bps, 8 data bits, even parity, 1 stop bit)
  2. Set DS2 to the board Modbus address (1 to 15). Enter the same number in MODBUS Address
  3. When using an IP/RS-485 converter, set it to 19200 8 even 1 none
DS1 (serial) and DS2 (address) - black shows the switch position
DS2 positions for addresses 1 to 15

2 — Add the gateway

  1. In Composer Pro, add the 4Drivers Daikin DTA116A51 VRV VRF UI and connect Serial RS-232 to the controller serial port (or to the IP converter driver)
  2. Check MODBUS Address = DS2 address
  3. Enter the License Key (or keep "Trial") and check Validation

3 — Find the units

  1. Under Actions, run Scan Units (or "Find units" in the Web UI)
  2. Message lists the Unit IDs that answered

4 — Add the thermostats

Add one 4Drivers Daikin Thermostat per indoor unit and fill in its Unit ID, calculated from the address shown on the Daikin controller:

DIII-Net groupAddresses on the Daikin controllerUnit ID
11-00 ... 1-150 ... 15
22-00 ... 2-1516 ... 31
33-00 ... 3-1532 ... 47
44-00 ... 4-1548 ... 63

Example: unit 2-05 = Unit ID 21 (16 + 5).

Done. The cards follow the real state of the units, including changes made on the Daikin controller. Communication Status shows OK while the board answers.

On and Off Methods

The DTA116A51 only forwards a command to the VRV when the value it receives differs from the last one it stored. When the customer uses the original Daikin controller, that stored value does not change - and the next on/off from Control4 may be ignored. Off Method and On Method choose how the driver works around it.

V2Same as the plain off command.Avoid

VRV Groups (Master ID)

Only for sites with more than one outdoor unit. In each group the master unit decides Cool/Heat for the whole group; a slave asking for Cool while its master is in Heat may have no effect.

  • Master ID 1: Unit ID of the master unit of group 1 (-1 = off)
  • Master ID 1 Slaves: Unit IDs of the group, comma separated (e.g. 2,3,6)
  • Same for groups 2 and 3

When a slave turns on or changes mode, the driver first sets only the mode of its group master - without turning the master unit on.

Web UI

  • One card per unit on the page: mode (including Auto and Dry), fan, louver, setpoint and room temperature
  • Malfunction/warning alerts with the Daikin code, Forced Off, filter, sensor error and Cool/Heat master
  • Find units: tap a unit found to show it on or remove it from the page (with or without a thermostat)
  • Rename: tap the card name. When the unit's thermostat is renamed in the project, the page follows
  • All Off (units on the page)
  • List, names and last scan result are saved
  • Debug panel (🐞 icon) to diagnose communication between the page and the driver
With the unit off, the chosen fan and louver are stored and applied when it turns on. The setpoint can be changed while the unit is off.

Coming from the previous driver (64 outputs)

This driver replaces the 64 "Daikin UNIT-n" outputs with a single connection. The old UNIT-n output number is the Unit ID of the new thermostat. MODBUS Address, Commands Delay, Off/On Method and Master ID work the same.
